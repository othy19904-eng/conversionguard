# Distribution test

The current goal is not more features. It is evidence from real stores.

## ICP

Start broad inside existing spend:
- Shopify merchants running paid acquisition;
- ecommerce agencies managing GA4 / Google Ads tracking;
- analytics and tracking consultants.

## Pilot message

"ConversionGuard compares real order truth against measured purchase conversions and flags missing, duplicate, value and currency defects. The first audit can run from two exports, so no production write access is needed."

## Measure

Track:
- qualified repository visitors;
- demo runs;
- pilot requests;
- completed real-store audits;
- defects found or confidently ruled out;
- willingness to pay;
- paid audits / monitoring conversions.

## Stop rule

Do not build a dashboard or billing system before:
- 3 real stores have been audited; and
- at least 1 merchant or agency is willing to pay.
